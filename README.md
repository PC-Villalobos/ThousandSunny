# ThousandSunny

ThousandSunny is the trunk repository for the Thousand Sunny cognitive
ecosystem: canon, crew manifests, gardens, seeds, nursery projects, and the
records that explain why the system is shaped this way.

The ship has two forms:

- When it navigates the WWW, it is a vessel: agents, tools, bridges, bots, and
  operational workflows.
- When it rests and organizes memory, it is a tree: trunk, branches, gardens,
  seeds, leaves, and fruits.

## Repository Roles

The current topology keeps only two repositories:

| Repository | Role |
| --- | --- |
| `pc-villalobos/thousandsunny` | Trunk: canon, agents, gardens, seeds, nursery, Bitacora. |
| `pc-villalobos/puentedemando` | Operative bridge: UI and console for the ship. |

New repositories are created only when a line graduates into its own lifecycle.
Until then, projects live in this trunk as folders with manifests and IntentIDs.

## Navigation

| Path | Purpose |
| --- | --- |
| `docs/intent-tree/` | Living map of the trunk, seed, branches, and graduation rules. |
| `docs/manifests/` | Stable IntentID declarations for active intention families. |
| `crew/` | Named crew agents with continuous identity. |
| `agents/institutional/` | Functional and transversal institutional agents. |
| `gardens/` | Stable domains where projects become ecosystems. |
| `seeds/` | Reproducible origins for future lines. |
| `nursery/` | Projects in gestation before repo graduation. |
| `bitacora/` | Human-readable decision log mirrored by operational Bitacora. |

## Rule

The intention lives in canon. The Git branch lives only while changing
something. The artifact is the proof.

Private repository.
