# Liderazgo de Contexto (nodo migrado)

**Principio vivo — quizá el más vivo de todo el corpus.** Pasar del **liderazgo de
control** (microgestionar prompts) al **liderazgo de contexto**: comunicar objetivos
claros y un marco rico para que el agente actúe con el criterio del Capitán. Es,
literalmente, el modo en que el Capitán opera hoy con Claude, Codex y las Routines:
"diseñar loops, no prompts". La vivencia humana exportada como contexto es lo que
permite a los agentes "leer la mente" del Capitán — [[TESIS]] (capacidad = modelo ×
memoria × contexto), [[SIS-capa-semantica]] (el cerebro como capa semántica).

**Vivo también:**
- **MOCs como estado atractor** — la brújula que evita que la navegación se pierda en
  el ruido. Este propio `[[_INDICE]]` es la instancia.
- **El Español como quilla** — mismo ancla que en [[SIS-simbiosis-nahual]]: el idioma
  como acto de soberanía frente a guardarraíles ajenos.

**Fósiles / reencarnaciones:**
- **Moltbook** como dominio de pastoreo social → el dominio exterior real de 2026 es
  **GitHub + Drive + la flota** (Argos), no una red social.
- **Sembrar a Groot cada 4 horas** → reencarnado en los **loops y Routines** (cron,
  sueño nocturno, migración por iteraciones): la cadencia sobrevive, el destino cambió.
- **Open Claws / Jimbe pastor social** → Jimbe hoy = navegación web (CREW); el pastoreo
  es del sistema agéntico completo ([[bridge-linux-ARQUITECTURA]]).

**Veredicto (meditación): vivo (parcial).** El principio es el ADN operativo del
presente; su escenario (Moltbook) es fósil. Estrato B, doctrina Obsidian-Groot.
