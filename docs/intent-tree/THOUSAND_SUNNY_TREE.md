# Thousand Sunny Tree

ThousandSunny is the living trunk of the ecosystem. It is not only a code
repository; it is the shared canon that keeps origin, memory, projects, agents,
and deployable artifacts in one navigable system.

## Ontology

| Symbol | Repository shape | Meaning |
| --- | --- | --- |
| Trunk | `thousandsunny/` | Canon, memory, manifests, agents, seeds, and gardens. |
| Seed | `seeds/` | Reproducible origin for a future line. |
| Nursery | `nursery/` | Project in gestation before it needs its own repo. |
| Garden | `gardens/` | Stable ecosystem of intention and memory. |
| Branch | Temporary Git branch | Work front for a concrete operation. |
| Leaf | Institutional function | Rotable operational capacity. |
| Fruit | Artifact | Usable product: PR, report, game, bot, doc, app. |
| Prune | Archive/quarantine/retire | Controlled closure. |

## Rule

The intention lives in canon. The branch lives only while changing something.
The PR explains the change. Bitacora leaves the trace.

Permanent Git branches per intention are avoided because they drift into
parallel worlds. IntentIDs, manifests, folders, PRs, issues, and Bitacora carry
durable identity instead.
