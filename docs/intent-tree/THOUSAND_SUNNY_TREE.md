# Thousand Sunny Intent Tree

ThousandSunny is the living trunk. It is not only a repository: it is the
shared canon that keeps origin, memory, projects, and deployable artifacts in
one navigable system.

## Day 0

The Day 0 seed is the Caso Cero: Curso de Astrologia Terrestre. It is the
origin line that gave the ecosystem its first language, symbolic structure,
and reproducible pattern.

## Year 1

Year 1 is the ramification year. The trunk now grows stable intention families,
each with an `IntentID`, a canonical folder, and one or more temporary Git
branches for concrete operations.

Initial families:

| IntentID | Canon | Purpose |
| --- | --- | --- |
| `INT-GAIA-ARCADE` | `games/gaia-arcade/` | Evolutionary arcade game and playable Gaia learning loop. |
| `INT-PUENTE-2D` | `puentedemando/` | Command bridge interface and operational cockpit. |
| `INT-DRIVE-ISM` | `gardens/nemesis/` | ISM audit, memory intake, and classification flow. |
| `INT-QUIRON-M0` | `gardens/sofia/` | Quiron/Sofia knowledge line and structured synthesis. |

## Gardens

Gardens are stable domains where the ship rests as a tree instead of sailing
as a vessel.

| Garden | Canon | Rule |
| --- | --- | --- |
| `Nemesis` | `gardens/nemesis/` | Clinical and case-sensitive material. Handle only through approved gates. |
| `Agape` | `gardens/agape/` | Transmuted, desensitized, reusable learning and care patterns. |
| `Sofia` | `gardens/sofia/` | Academic, symbolic, and synthetic knowledge structures. |

## Git Rule

The intention lives in canon. The Git branch lives only while changing
something.

Use branches as temporary work fronts:

```text
intent/gaia-arcade-seed
intent/puente-2d-prototype
intent/drive-ism-batch001
fix/puente-double-render
```

Do not keep one permanent branch per family of intentions. Permanent branches
become parallel worlds that drift away from the trunk. The durable identity
belongs in folders, manifests, IntentIDs, issues, PRs, and Bitacora.

## Working Cycle

1. Create or update the canon folder for the intention.
2. Assign or reuse one `IntentID`.
3. Open a temporary branch for the concrete operation.
4. Commit the artifact and its manifest.
5. Merge back into the trunk.
6. Log the operation in Bitacora.
