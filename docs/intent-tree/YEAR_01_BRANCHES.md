## Git Branch Convention

Use temporary branch names that include intention plus operation:

```text
intent/gaia-arcade-seed
intent/puente-2d-prototype
intent/drive-ism-batch001
fix/puente-double-render
claude/branch-organization-strategy-dwcC1
```

Branches are merged or retired. Canon remains in folders and manifests.
